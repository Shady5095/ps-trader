# تطبيق إدارة تجارة أجهزة PS5

تطبيق Flutter كامل يحل محل ملف الإكسل، لإدارة عمليات شراء وبيع أجهزة PS5، بتصميم احترافي، إحصائيات ورسوم بيانية متطورة، وصور لكل جهاز.

## المميزات
- **لوحة إحصائيات (Dashboard)**: صافي الربح، متوسط الربح، عدد الأجهزة المباعة والمتوفرة.
- **رسوم بيانية متطورة** (باستخدام `fl_chart`):
  - الأرباح الشهرية (Line/Area Chart).
  - توزيع أنواع الأجهزة (Donut Chart).
  - الربح حسب نوع الجهاز (Bar Chart).
- **إضافة / تعديل / حذف** الأجهزة بسهولة.
- **قائمة ثابتة (Dropdown)** بكل موديلات PS5 (Fat / Slim / Pro - CD / Digital) عند إضافة جهاز جديد، بدل الكتابة اليدوية.
- **صورة لكل جهاز**: التقاط صورة بالكاميرا أو اختيارها من المعرض وحفظها مع الصفقة.
- **تسجيل عملية البيع**: سعر البيع، تاريخه، رقم المشتري، ويُحسب الربح تلقائيًا.
- **بحث وفلترة** حسب الحالة (بالمخزن / تم بيعه) أو الموديل أو المكان.
- كل البيانات تُحفظ محليًا على الجهاز (SQLite) - لا حاجة للإنترنت.

## طريقة التشغيل
1. تأكد إن Flutter SDK مثبت عندك: https://docs.flutter.dev/get-started/install
2. فك ضغط المجلد وادخل عليه:
   ```bash
   cd ps_trades_app
   flutter pub get
   ```
3. وصّل جهاز أو شغّل إيموليتور، بعدين:
   ```bash
   flutter run
   ```

## هيكل المشروع
```
lib/
  models/         # Trade + قائمة موديلات PS5 الثابتة
  services/        # قاعدة البيانات المحلية (sqflite) + حساب الإحصائيات
  providers/       # إدارة الحالة (Provider)
  screens/         # الشاشات (Dashboard, List, Add/Edit, Details)
  widgets/         # كروت وعناصر واجهة قابلة لإعادة الاستخدام
  widgets/charts/  # الرسوم البيانية
  theme/           # الألوان والخطوط
```
